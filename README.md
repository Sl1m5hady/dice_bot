# Кубомет

Общий чат для D&D на FastAPI и в Telegram. В поле ввода можно написать сообщение или бросок вроде `d20kh+5`. Нажатие на сердце сохраняет исходный текст или формулу в избранное. В боковой панели можно изменить описание и подставить запись обратно в поле ввода. UID персонажа, имя и избранное хранятся в браузере, последние 100 записей чата — в SQLite.

## Запуск

Скопируйте `.env.example` в `.env` и создайте каталог для файлов бота.

```bash
cp .env.example .env
mkdir -p secrets
```

- `TELEGRAM_TOKEN` — токен от [@BotFather](https://t.me/BotFather). Если значение пустое, Compose читает `secrets/token.txt`, а прямой запуск Python — `token.txt` в корне проекта. Переменная окружения имеет приоритет над `.env`.
- `TELEGRAM_CHAT_ID` — начальный адрес Telegram. Для группы укажите отрицательный ID, для лички — положительный. Пустое значение запускает отдельный веб-чат.
- `WEB_ACCESS_CODE` — общий код для игроков. `WEB_SESSION_SECRET` — отдельный ключ подписи cookie. Для каждого значения можно использовать отдельный результат команды `openssl rand -hex 32`.
- `WEB_ADMIN_CODE` — необязательный отдельный код для настроек Telegram в вебе. Используйте значение, отличное от общего кода игроков.
- `DICE_DOMAIN` и `CERTBOT_EMAIL` нужны для автоматического HTTPS. Укажите доменное имя, например `dice.example.org`.

`.env`, файлы с токенами и локальная база исключены из Git и контекста сборки.

### Локально через Podman Compose

Нужен Podman с провайдером Compose, например `podman-compose`.

```bash
podman compose -f compose.yaml -f compose.local.yaml up -d --build
```

Сайт откроется на `http://127.0.0.1:8080`. SQLite хранится в именованном томе Compose и переживает перезапуски контейнера.

### На сервере с автоматическим HTTPS

Направьте DNS домена на сервер и откройте входящие TCP-порты 80 и 443. В Linux rootless Podman обычно использует порты от 1024. Для привязки к 80 и 443 запустите Compose через `sudo` или используйте уже настроенный доступ rootless Podman к низким портам. [Документация Podman](https://github.com/podman-container-tools/podman/blob/main/rootless.md)

```bash
sudo podman compose -f compose.yaml -f compose.prod.yaml up -d --build
sudo podman compose -f compose.yaml -f compose.prod.yaml logs -f certbot nginx
```

При первом запуске Certbot проверит домен через Nginx и выпустит сертификат Let’s Encrypt. Nginx включит HTTPS, как только появится сертификат. Продление и перечитывание сертификата выполняются автоматически. [Проверка домена](https://letsencrypt.org/docs/challenge-types/#http-01-challenge)

Те же файлы Compose поддерживают запуск командой `docker compose`.

### Для разработки без контейнеров

Откройте Bash в корне проекта и подготовьте виртуальное окружение.

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
uvicorn web_app:create_app --factory --host 127.0.0.1 --port 8000
```

Telegram-бот запускается отдельно командой `python main.py`.

### Подключение группы или лички Telegram

Запустите бота и отправьте `/chatid` в нужном чате. Для группы сначала добавьте туда бота. Чтобы он получал обычные сообщения группы, сделайте его администратором или отключите Privacy Mode через `/setprivacy` у @BotFather и добавьте бота заново. [Режим приватности Telegram](https://core.telegram.org/bots/features#privacy-mode)

Для теста в личке сначала отправьте боту `/start`, затем `/chatid`. При подключении лички её новые сообщения с ботом видны всем вошедшим в веб-чат. [Правила личных сообщений ботов](https://core.telegram.org/bots#how-do-bots-work)

Если задан `WEB_ADMIN_CODE`, войдите по общему коду, откройте шестерёнку и введите отдельный код администратора. Сохраните полученный ID. Кубомет переключится без перезапуска. Пустое поле отключает связь с Telegram. Выбор из админки сохраняется в базе и имеет приоритет над `TELEGRAM_CHAT_ID`. При переключении каждый чат сохраняет свою историю, а ожидающие сообщения отправляются только при подключении их исходного чата.

Синхронизация начинается с новых текстовых сообщений. Бот отправляет сообщения с сайта с подписью `Имя персонажа · веб`. В связанном чате одна формула на всю строку запускает бросок, например `2d6+3 — Урон мечом`. Результат считается один раз и появляется в обоих интерфейсах. Веб-чат обновляется каждые 3 секунды. После подключения прежние броски сайта остаются в истории.

В режиме Compose сайт и бот используют общий именованный том. При прямом запуске задайте обоим процессам один `WEB_DB_PATH` или запустите их из корня репозитория с настройкой по умолчанию.

## Синтаксис

Поддерживаются кубики `d4`, `d6`, `d8`, `d10`, `d12`, `d20` и `d100`. В формулах можно использовать `+`, `-`, `*`, `/`, `//` (деление с округлением вниз), `**` (степень) и вложенные скобки. В десятичных числах используется точка.

| Сообщение | Действие |
| --- | --- |
| `d20` или `d20()` | Бросить один d20 |
| `3d6`, `3d6()` или `d6(3)` | Сложить три броска d6 |
| `2к20` или `2к20()` | Использовать кириллическую `к` вместо `d` |
| `(2d6()+5)*2` | Удвоить сумму двух кубиков и модификатора |
| `d20kh` | Преимущество. Бросить два d20 и оставить наибольший результат (`2d20kh1`) |
| `d20kl` | Помеха. Бросить два d20 и оставить наименьший результат (`2d20kl1`) |
| `4d6kh3` | Сложить три наибольших из четырёх бросков |
| `d20; 2d6+3` | Выполнить два отдельных броска в режиме обычного Telegram-бота |
| `2d6+3 — Урон мечом` | Добавить подпись до конца строки |

Если после `kh` или `kl` не указано количество оставляемых кубиков, бот оставляет один. Если при этом не указано и число бросков, бот бросает два кубика. Например, `4d6kl` равнозначно `4d6kl1`, а `d20kl+5` — `2d20kl1+5`.

### Примеры ответов

- `2d20()+5` при бросках 20 и 11 → 🔥20 + 🎲11 + 5 = **36**
- `2d20kl1+5` при бросках 1 и 20 → [💀1, ~~🎲20~~] + 5 = **6**
- `(2d6()+5)*2` при бросках 4 и 6 → (🎲4 + 🎲6 + 5) × 2 = **30**

🔥 и 💀 отмечают выбранные натуральные 20 и 1 на d20. Эти отметки влияют только на отображение. Отброшенные по `kh` или `kl` кубики зачёркиваются.

### Большие формулы и броски

Формулу до 33 000 символов можно отправить в `.txt`-файле в кодировке UTF-8. Пишите каждую формулу на отдельной строке. Бот ответит на исходный файл. Бросок `1000d6` можно отправить и обычным сообщением. Если для результата требуется больше десяти сообщений, бот пришлёт `roll-results.html` со всеми кубиками и итогом.

## Ограничения

- В общем чате — одна формула в сообщении. В режиме обычного Telegram-бота — до пяти формул в сообщении или файле. На формулу — до 33 000 символов и 33 000 кубиков суммарно. Размер входящего `.txt` — до 132 000 байт.
- До 120 символов в подписи. Подпись к следующей формуле можно указать на новой строке.
- Абсолютная величина промежуточных и итоговых чисел ограничена `10**100`, показателя степени — `100`.
- До 5 запросов на пользователя за 10 секунд. Очередь отправки учитывает лимит чата и `retry_after` при ответе Telegram `429`. Общий объём HTML-файлов в очереди — до 32 МиБ.

## Тесты

Из корня проекта установите зависимости проекта и HTTP-клиент для тестов, затем запустите набор проверок.

```bash
python -m pip install -r requirements.txt httpx==0.28.1
python -m unittest discover -v
```

Тесты проверяют вычислитель, вход, миграцию истории и двусторонний обмен с Telegram с подменой сетевых вызовов.
